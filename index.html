WebWatch — Outil de Web Monitoring Intelligent

Création d'une application web complète de surveillance de sites internet avec détection automatique des changements par intelligence artificielle.

Lire la suite...

Le défi : Construire un système capable de surveiller plusieurs URLs en temps réel, de détecter les moindres modifications de contenu et d'en produire un résumé intelligible grâce à l'IA.

Mon approche :

  • Scraping : Extraction automatique du contenu de chaque page en Markdown via Firecrawl API.
  • Versioning : Stockage et comparaison des snapshots successifs dans une base Redis (Upstash) pour détecter les différences.
  • Analyse IA : Utilisation de GPT-4o (OpenAI) pour résumer les changements détectés en langage naturel.
  • Interface : Dashboard sombre moderne avec timeline interactive des modifications et notifications en temps réel.

Résultats : Application full-stack déployée en production, capable de surveiller un nombre illimité de sites, de comparer les versions et de produire une analyse IA des changements toutes les 24h automatiquement.

Outils utilisés : Next.js 15, TypeScript, Tailwind CSS, Framer Motion, shadcn/ui, Firecrawl, OpenAI GPT-4o, Upstash Redis, Vercel.

Le défi : Transformer des données brutes massives (Data.gouv) en indicateurs visuels exploitables pour comprendre les besoins énergétiques par territoire.

Mon approche :

  • Granularité : Analyse précise à l'échelle de l'IRIS (quartier) pour localiser les zones de forte activité.

Analyse Macroéconomique & PIB (Modélisation)

Analyse des moteurs économiques et prédiction de l'évolution du PIB à l'aide de modèles de régression avancés.

Lire la suite...

Le défi : Comprendre les mécanismes complexes de la croissance économique pour construire un modèle prédictif capable d'anticiper les variations du PIB.

Mon approche :

  • Traitement & Visualisation : Nettoyage de données complexes et création de tableaux de bord pour visualiser les tendances clés.
  • Machine Learning : Comparaison rigoureuse de modèles de régression via Scikit-Learn pour sélectionner la meilleure approche prédictive.
